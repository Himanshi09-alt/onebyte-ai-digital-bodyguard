ONEBYTE – AI DIGITAL BODYGUARD v2.0
“Know What You Share Before It Becomes a Risk.”

WHAT CHANGED
- Preserved the original visible-text scanner and its privacy boundary.
- Redesigned the popup as a premium privacy command center.
- Added animated scan flow, risk overview, explainable “Why am I seeing this?” section, insights, local risk history, settings and technical flow.
- Added consistent inline SVG cybersecurity icons (no external dependency).
- Added categories for data sharing, tracking, permissions/location, personal data, consent, photos and contacts.
- Scan results are still generated from actual visible page text; demo history is clearly labeled.

INSTALL
1. Extract this ZIP.
2. Chrome/Chromium → chrome://extensions
3. Enable Developer mode.
4. Load unpacked → select the extracted folder.
5. Open a normal webpage and click the ONEBYTE extension icon.

DEMO
Open demo.html from the extracted folder in Chrome, then click the extension.
The demo page intentionally includes privacy signals.

IMPORTANT
This remains a hackathon prototype, not a production security product.
The score is a transparent rule-based attention score, not a guarantee of safety.
The extension excludes input, textarea, select, button, script, style, noscript and iframe elements before reading visible text.
It does not read typed passwords, OTPs, card values or other form values.
